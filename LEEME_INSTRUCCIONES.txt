CÓMO SUBIRLO A GITHUB

Opción A (la más rápida — arrastrando las carpetas):
  1. Descomprime el ZIP en tu computadora.
  2. Entra al repositorio en GitHub, a la raíz (donde se ven las carpetas
     api, lib y public).
  3. Add file -> Upload files.
  4. Arrastra las TRES carpetas (public, api, lib) al recuadro. GitHub
     respeta las rutas y reemplaza los archivos que ya existían.
  5. Commit changes.

Opción B (tu proceso de siempre, archivo por archivo):
  Para cada archivo: entra a su carpeta -> clic en el archivo -> lápiz ->
  tres puntos "..." -> Delete file -> Commit. Luego regresa a la carpeta ->
  Add file -> Upload files -> sube el archivo nuevo.
  Ojo: verifica que el nombre no traiga "(1)" o "_2" si Windows lo renombró.

EL EXCEL DE DESCARGA (lo nuevo del 14 de septiembre)

  1. Filas "Sin Calificacion".
     El archivo ya no trae solo lo que se capturó: por cada persona y cada
     día laborable en que se esperaba calificación y no hubo ninguna, se
     genera una fila con Tipo = "Sin Calificacion". Así puedes filtrar por
     esa palabra y ver de un golpe quién se quedó sin calificar y qué día.
     · Solo lunes a viernes (sábado y domingo no generan días esperados).
     · Solo dentro del periodo real de cada persona: desde su fecha de alta
       y hasta el día anterior a su fecha de baja.
     · El personal con baja definitiva no genera estas filas (ya no es
       plantilla); sus calificaciones reales sí siguen apareciendo.
     · El día de hoy aparece como "Sin Calificacion" mientras no se capture,
       igual que ya cuenta como pendiente en el KPI.
     IMPORTANTE: estas filas se calculan al momento de exportar. NO se
     guardan en la base de datos: la base sigue teniendo únicamente lo que
     los supervisores capturaron de verdad.

  2. Encabezados con el nombre de la pregunta.
     Las columnas P1…P10 ahora se llaman con el texto completo de cada
     pregunta del checklist. El resto de las columnas no cambió de nombre
     ni de orden.

  3. TISA se descarga aparte, con su propio botón.
     TISA tiene otras 10 preguntas (seguridad química), así que mezclarla
     con el resto pondría calificaciones debajo de encabezados que dicen
     otra cosa. Ahora hay dos botones:
       "Exportar Excel"       -> todas las sucursales MENOS TISA
       "Exportar Excel TISA"  -> solo TISA, con sus preguntas
     Los dos respetan el periodo elegido y los dos generan la hoja "Datos".
     Si eliges TISA en el selector de sucursal y aprietas el botón general,
     la app te avisa y te manda al botón correcto en vez de darte un
     archivo vacío.


CONSUMO DE LA BASE DE DATOS (lo nuevo del 14 de septiembre)

  El problema: la app le preguntaba al servidor cada 12 segundos desde CADA
  navegador abierto, y en cada vuelta se descargaba la tabla completa de
  evaluaciones. Con las pestañas de los supervisores abiertas toda la
  jornada, la base de datos nunca alcanzaba a suspenderse y se consumían
  las horas de cómputo del plan gratuito de Neon.

  Lo que cambia:
  · El sondeo pasa de 12 a 60 segundos.
  · Se detiene por completo mientras la pestaña no está a la vista, y se
    refresca al instante cuando vuelves a ella (no se nota al usarla).
  · El supervisor ya solo pide el día de hoy, que es lo único que ve su
    pantalla, en vez de toda la base. El Admin sigue trayendo el histórico
    completo una sola vez al entrar, porque lo necesita para reportes,
    PDF y exportación.
  · El catálogo de personal se pide cada 5 minutos en vez de cada 12
    segundos.
  En conjunto, una pestaña abierta pasa de unas 600 peticiones por hora a
  unas 70 cuando se está usando, y a CERO cuando está en segundo plano.

  Además, si la base de datos se queda sin cuota:
  · La app ya no dice "verifica tu conexión a internet": muestra el motivo
    real que manda el servidor.
  · Las migraciones dejaron de ser obligatorias para poder leer. Si la base
    queda en solo lectura, el Admin todavía puede consultar los reportes y
    DESCARGAR EL EXCEL con el histórico. Lo que no se podrá hacer es
    guardar calificaciones nuevas hasta que se libere la cuota.
